This is an unofficial build from **shinova55/dsh-free-model**, based on upstream through `25151bab43ff28bfc0eef5a3dbec4443ecc6d2f2`. The release follows the download and verification format of upstream v2.5.4.

## Versions and changes

- Plugin package: **2.5.5** (upstream's plugin startup sponsor change included).

- English default README, Chinese documentation retained, Windows build guide included.
- API behavior, authentication flows and account identifiers retain their existing implementation.

## Install or update on Windows

1. Download the x64 setup file and `SHA256SUMS.txt` from this release.
2. Verify the file with PowerShell: `Get-FileHash '.\Our Free Model_2.5.4_x64-setup.exe' -Algorithm SHA256` and compare it with the checksum file.
3. Fully quit the running application from its tray menu before installing. Back up your existing application data first. Do not delete your data directory or account files.
4. Run the installer, reopen the app, then select English under Service settings → Language / 语言.

The installer is **not Authenticode signed**. Windows may show an unknown-publisher warning. Verify the repository, release and checksum before choosing whether to run it. Checksums detect altered downloads; they are not a publisher signature.

This release process does not access or change your locally installed settings or credentials. An in-place upgrade is intended to retain existing data, but a native upgrade with real account data has not been manually tested for this fork build.

## Plugin installation

Use the attached `.tgz` with your dsh host's managed plugin installation flow. The plugin requires its host; it is not a standalone Windows executable. Keep the previous plugin archive for rollback.

## Verification and scope

The release workflow builds on Windows, checks TypeScript, rebuilds the web UI, verifies the existing manifest, runs the contributor suite and the Chinese/English browser regression tests, then builds the NSIS installer and plugin archive. See the attached report and linked Actions run for exact results.

Native tray/startup dialogs and sponsor content are still Chinese. Third-party account pages and user-provided text are not translated. Native GUI installation and real-provider sign-in have not been manually exercised on this generated installer. The upstream sponsor-animation browser suite has a known baseline failure and is not part of this release workflow. This fork does not claim upstream publisher signing or certification.

## Rollback and building from source

Quit the application before reinstalling a previous trusted installer. Preserve your data backup and do not erase account/settings files to roll back. Plugin users can reinstall their previous archive through the host.

See [the Windows build guide](https://github.com/shinova55/dsh-free-model/blob/main/docs/WINDOWS-LOCALIZATION.md). The `Windows fork release` Actions workflow provides the reproducible build steps used for these assets; its run is recorded in the verification report.
